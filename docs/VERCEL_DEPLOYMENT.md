# Vercel hosting

The Next.js frontend and API routes run together on Vercel. The existing Supabase project stores accounts, administrator approval, quizzes, progress and learning content. Vercel does not require a Render wake-up schedule.

Use Node.js 24. Deploy the reviewed commit with `vercel deploy --prod --skip-domain`, verify it, then run `vercel promote <deployment-url>`. Link the intended project and team before setting environment variables. Keep private values in Vercel's production environment; never include `.env.local` or `.local` in deployment uploads.

Required production settings:

- `SUPABASE_URL` and `SUPABASE_SECRET_KEY` (or `SUPABASE_SERVICE_ROLE_KEY`) from the existing configured project.
- A separate random `SESSION_SECRET` with at least 32 characters.
- `APP_ORIGIN` set to the production HTTPS domain.
- `ENABLE_DEMO_DATA=false`, `NEXT_PUBLIC_ENABLE_DEMO_LOGIN=false` and `STUDENT_ACTIVATION_MODE=admin`.
- `TEXTBOOK_DELIVERY=official`. Checked-in catalog entries map to exact SCERT PDF URLs through Next.js rewrites, keeping the reader on the same website without uploading the laptop's 2.20 GiB library. Only the catalog's HTTPS CloudFront source is allowed.
- `AI_PROVIDER=excerpts`. The study helper returns matching study material with citations. The Windows Gemma executable and model are local software and are not deployed to Vercel; generated model answers require a separately provisioned model host.

The `.vercelignore` file excludes private credentials, downloaded textbooks, source videos/PDFs and the local model. The imported notes and videos already live in Supabase Storage and remain available online. PDF.js assets are regenerated by `npm ci` and `npm run build`.

Administrator uploads request a signed, single-file upload URL from `/api/admin/content/upload`, then send the file directly to Supabase Storage. This avoids sending large file bodies through Vercel Functions. The endpoint requires an active administrator session, validates size/type, generates the destination itself and cannot overwrite an existing object. The storage bucket enforces the 50 MiB upload limit and allowed MIME types. No server key is returned to the browser.

Verify student and administrator login, role restrictions, notes, video playback, textbook PDF range requests, a direct storage upload and durable progress before promoting the production build.
